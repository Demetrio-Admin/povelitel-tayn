# 25 отдельных рисунков противников — 23.10.2026

Новый набор состоит из 25 индивидуально отрисованных изображений, одобренных владельцем в чате. Он заменяет прежние вырезки из общего арт-листа. Нумерация 01–25 сохранена.

- `public/assets/monster-redesign/01.webp`…`25.webp`: целые исходные изображения, уменьшенные с сохранением пропорций и альфа-канала до 768 пикселей по длинной стороне. Силуэты не вырезаются из таблицы и не обрезаются.
- `src/config/monster-redesign.art.js`: соответствие всех 25 текстур файлам и размеры холста; версия URL обновлена для обхода старого кеша.
- Высоты в мире сохранены, ширина соответствует пропорциям изображения. Хранитель сердца имеет отдельный рисунок и высоту 230 пикселей.
- Мирон использует свой рисунок и на карте, и в бою через существующий `spawn.texture`.
- Противники третьей главы с новым рисунком исключены из списка прототипной графики.
- Боевые характеристики, экономика, квесты, сохранения, дружелюбные NPC и портреты не изменены.

Проверки: декодирование 25 RGBA WebP, уникальность всех файлов, соответствие манифесту, тесты проекта и production-сборка. Проверка в живом браузере отмечается отдельно.
