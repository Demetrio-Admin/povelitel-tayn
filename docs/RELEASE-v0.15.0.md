# v0.15.0 — дверь `sync_player` закрыта

**Нужно сделать вручную, в таком порядке:**
1. **SQL.** Supabase → SQL Editor → вставить весь файл `supabase/schema.sql` → Run. Безопасно запускается повторно, прогресс игроков не трогает (новая `sync_player`, операции `event` / `quest_accept` / `quest_turn_in` / `research_start` / `research_finish` / `respec`, расширенная `world`, обновлённые правила).
2. **Edge Function `combat`.** Supabase → Edge Functions → `combat` → вставить заново весь файл `supabase/functions/combat/index.ts` → Deploy (в нём вшиты правила игры, они изменились). Проверку входа (JWT) оставить включённой.
3. Только потом выкладывать игру (merge в `main`).

Что видит игрок: всё то же. Награды, события, дары и изучение подтверждает сервер; подделать их через консоль браузера больше нельзя. Тем, у кого открыта старая вкладка, нужно обновить страницу.

Известное ограничение: позиция героя всё ещё приходит от клиента, поэтому быструю ману «в доме Мирры» можно подделать (награды — нет).

Откат: `git revert -m 1 <merge-коммит>` вместе с возвратом прежнего `schema.sql` (и прежней функции `combat`, если её обновляли). Откатывать только игру нельзя: старая игра пишет закрытые поля через `sync_player`, а новая база их не принимает.
