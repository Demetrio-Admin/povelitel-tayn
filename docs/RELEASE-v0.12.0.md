# v0.12.0 — жизнь и мана на сервере

**Нужно выполнить SQL:** открыть Supabase → SQL Editor → вставить весь файл `supabase/schema.sql` → Run. Скрипт безопасно запускается повторно, прогресс игроков не трогает (добавляет два поля и обновляет функции). Выполнить нужно **до** или сразу после выкладки игры: старая игра с новой базой работает, но не записывает HP и ману.

Что видит игрок: HP и мана восстанавливаются, даже когда игра закрыта (HP 1/с, мана 0,5/с, в доме Мирры 2/с); во время боя восстановление стоит; зелья из сумки и лечение у Мирры считает сервер. Бой начинается только при связи с сервером. Описание — README, раздел «v0.12.0».

Откат: `git revert -m 1 <merge-коммит>` и вернуть прежний `schema.sql` (новые поля `vitals_at` и `combat_since` старой игре не мешают, их можно оставить).
