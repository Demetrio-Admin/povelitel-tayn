# v0.36.0 — просторный город, отдельные помещения и графика Банка и Архива

Игровая планировка согласованного города: центральная улица шириной 800 пикселей, отдельная полоса 360 пикселей под будущие кареты, поперечные проходы и свободные площадки перед домами. Банк и Архив получили индивидуальные фасады и оформленные интерьеры из выбранного дизайн-пакета. На улицах — новая каменная мостовая, на площади — фонтан с обычным и замёрзшим состояниями, скамейки и цветы. Остальные десять фасадов используют прежние игровые изображения; их индивидуальная графика и городской трафик остаются следующим этапом.

Новые помещения собраны из отдельных спрайтов: стены, паркет, стойка, книжные шкафы, письменный стол и ковры. Мебель перекрывает персонажа в зависимости от его положения, пол и ковры проходимы. Агата стоит за стойкой, нажатие на неё ведёт к месту посетителя перед стойкой. Илария и отдельный квестовый документ доступны через широкий центральный проход Архива. Подписи на фасадах рисуются игрой. Добавлены 14 WebP-изображений с отдельными ключами; старые файлы сохранены. Описания генерации находятся в `public/assets/city-final/provenance.json`.

Банк, Архив, Общество Преображения, лаборатория, Дуэльный зал, Ковены, складской комплекс и два спасаемых дома открываются отдельными игровыми сценами через кнопку действия. Комната занимает игровое поле, камера следует за героиней. Два складских входа ведут в одно помещение: прежние враги и предметы существуют в единственном экземпляре. Два северных фоновых дома остаются без входов. Дом Мирры сохраняет прежнее поведение.

Илария и документ находятся внутри Архива; его вход доступен до первой беседы. Печать лаборатории и преграды Дуэльного зала остаются снаружи. Лаборатория, зал и два спасаемых дома открываются по прежним квестовым событиям. Наведение показывает нужную дверь, а при цели снаружи — выход из комнаты. Карта мира показывает четыре внешние локации.

Комнаты используют отдельные области общего координатного пространства. Сохранение x/y определяет текущую комнату без изменения формата базы. Старые городские позиции переносятся в доступную часть новой карты; сохранённые перемещения телекинезом получают новые координаты. Сюжетные идентификаторы, условия, награды и баланс сохранены. Новые двери не выдают наград. Сетка маршрутов строится только для текущей локации, чтобы расширение карты не увеличивало расход памяти каждого поиска пути.

Редактор сохраняет отметку `layout: 2`: прежние городские правки не возвращают старую застройку, новые правки города и помещений сохраняются. Идентификаторы остальных стен и номера шума остальных дорог стабильны.

## Проверка и выпуск

`npm test`, `npm run test:admin`, `npm run build`, `npm run check:bundle`, `npm run test:city-rooms`, `npm run test:city-graphics`.

`test:city-graphics` проверяет реальные нажатия на Агату через стойку, разговор с Иларией и применение Астрала к отдельному документу, а также смену состояния нового фонтана. Проверка проходит на 390×844, 320×568 и 1280×900. Снимки показывают реальные игровые сцены с героиней, без временных уведомлений.

Браузерный тест проверяет 390×844, 320×568 и 1280×900: входы/выходы, движение в комнатах, перезагрузку внутри банка и закрытую лабораторию. Дополнительная проверка 390×844 покрывает нажатие на пол для движения, границы камеры и перезагрузку посреди настоящего боя на складе: возврат в ту же комнату, ручной повтор и отсутствие награды за прерывание. Проверка карты покрывает все фасады и комнаты, северные квестовые преграды, старые сохранения и черновики редактора. Снимки создаются вне репозитория в `CITY_SHOTS_DIR`.

Правила `_game_rules()` и формат таблиц не меняются. При выпуске обновить сгенерированный `supabase/functions/combat/index.ts`; для установленной админки повторно применить актуальную идемпотентную `supabase/migrations/20261008_test_admin.sql`, чтобы её точки перемещения соответствовали новой карте. Это изменение подготовлено в отдельной ветке, публикация выполняется после просмотра.
