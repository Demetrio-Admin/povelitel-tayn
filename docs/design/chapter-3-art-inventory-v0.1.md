# Глава III — список графики (прототип v2)

Вся графика главы нарисована кодом: `python3 tools/art/ch3_grove_art.py` (PIL + numpy; пересобирает `public/assets/chapter3/*.webp`,
`src/config/chapter3.art.generated.js` и контактный лист `docs/design/chapter-3-art/contact-sheet.png`).
Второй проход (`tools/art/ch3_props.py`) собирает стеклянный мир из нарисованных спрайтов глав I–II через холодную палитру, чтобы толщина
контура, свет и текстура совпадали с остальной игрой. Это временная графика (TEMPORARY_ART): для релиза её заменит рисованная.

| Группа | Спрайты | Основа |
|---|---|---|
| Деревья | стеклянные и живые ивы, сухая ива, росток, Ракита (стеклянная / живая) | процедурные ивы (`ch3_trees.py`), шрам «замёрзшего огня» на Раките |
| Преграды | плотина, стена, тонкая стена-иней, валун, мост (целый / замёрзший), корни, кокон, завеса Астрала | `ice_wall`, `frost-ground`, `heavy_boulder`, `wooden_bridge`, `ward` (глава II), процедурные корни и кокон |
| Сад Ивы | колпаки с малиновкой, лисёнком, цветами, разбитый колпак, дом Ивы, эхо | `life-bird`, `frost_critter` (в рыжий), `flower_*`, `city_house`, `resident_woman` |
| Сбор | стеклянные тростники, искра памяти, ивовая кора (бревно), стеклянный лист на подставке | `reeds`, `rock_small`, `icon_ember`, `resin_log`, `frost_herb` |
| Полосы и земля | ручей (стекло / вода с бродом), трещина, стеклянная и сухая земля, заросли | `stone_path`, `snow_ground`, `grave_ground`, `ice_wall` |
| Персонажи | Ива молодая и старая, Безымянная, Ветла, портреты | перекраска `nerys`/`ilaria`, стеклянная обработка |
| Враги | стеклянный горностай, стеклянная волчица, эхо, игольник, элитный игольник, страж, Отражение Ивы | перекраска `frost_critter`, `frost_wolf`, `grave_wisp`, `frost_collector`, `ice_guardian` |
| Предметы | стеклянный лист, искра памяти, ивовая кора, семя Ветлы, Отвар памяти | `frost_herb`, `icon_ember`, `resin_log`, `potion_warm` |
| Арены и карта | арены «роща» и «сердце рощи», карта мира с рощей | `arena_frostwood`, `world-map` |

Что ещё стоит нарисовать вручную для релиза: портреты Ивы и Ветлы, Отражение Ивы (отдельный образ), Ракита в двух состояниях,
колпаки с животными, стеклянные игольники, кокон с ростком, иконки Отвара памяти и семени.
