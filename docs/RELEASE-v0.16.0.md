# v0.16.0 — Огонь III, Астрал III, слоты даров и амулеты

**Нужно сделать вручную, в таком порядке:**
1. **SQL.** Supabase → SQL Editor → вставить весь файл `supabase/schema.sql` → Run. Безопасно запускается повторно, прогресс игроков не трогает. Добавляет операции `build_set` / `build_preset`, правила слотов и амулетов и **закрывает служебные функции** (`_set_branch`, `_unlock_ability`, `_open_path`, `_set_event` раньше можно было вызвать из браузера).
2. **Edge Function `combat`.** Supabase → Edge Functions → `combat` → вставить заново весь файл `supabase/functions/combat/index.ts` → Deploy (в нём вшит боевой движок: лужа, вспышка, слоты, амулеты). Проверку входа (JWT) оставить включённой.
3. Только потом выкладывать игру (merge в `main`). Тем, у кого открыта старая вкладка, нужно обновить страницу.

Что видит игрок: ступень III у Огня (Поджигатель / Взрывник) и Астрала (Видящий / Пробивающий) — по достижении 8 уровня; блок «Билд» на экране «Дары» (слоты даров, два амулета, один бесплатный пресет); три амулета, которые дают задания «Падальщик у тропы» и «Пыль древних рун» и Лесной Страж.

Известные ограничения: слоты начнут что-то решать, когда даров станет больше трёх; источники амулетов временные (до ковена); экран «Дары» перед выкладкой стоит просмотреть в браузере (в среде сборки браузерные тесты запустить не удалось).

Откат: `git revert -m 1 <merge-коммит>`; прежний `schema.sql` и функцию `combat` вернуть вместе с игрой (новые ключи билда в `player_build` старая игра игнорирует).
