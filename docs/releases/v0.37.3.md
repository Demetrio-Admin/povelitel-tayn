# v0.37.3 — возврат прежнего экрана

По просьбе владельца отменено расширение карты на широких экранах из v0.37.1. На ПК снова используется портретное игровое окно с прежним расположением интерфейса; мобильный экран сохраняет адаптацию к высоте устройства.

Уютная графика города из v0.37.2, расположение домов, дорожки, декор и квесты сохранены. Сохранения игроков не меняются.
