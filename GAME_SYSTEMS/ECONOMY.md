# Экономика

SQL подтверждает награды, торговлю, крафт, расширение сумки, улучшения амулетов и изменения кошелька. `player_wallet` и `sapphire_ledger` хранят остаток и историю сапфиров. Транзакции и квитанции защищают подтверждённые начисления от повторов. Магазин сапфиров за реальные деньги остаётся запланированным.

Канонические правила находятся в `src/config/bag.js`, `recipes.js`, `shop.js`, `sapphires.js` и связанных конфигурациях. `serverRules.js` собирает их для SQL. Старые предметы, вместимость и `pending` входят в контракт совместимости.

Проверки: `npm run test:bag`, `npm run test:shop`, `npm run test:economy`, `npm run test:admin`.
