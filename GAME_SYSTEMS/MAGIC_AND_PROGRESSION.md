# Магия и развитие

Рабочие ID даров — `telekinesis`, `fire`, `seal`, `ice`, `storm`. Публичное имя `seal` — Астрал. `AbilitySystem` связывает применение дара и исследование с `GameState`. Уровни героя, силы и баланс описаны в `src/config/balance.*`. Текущий контент героя рассчитан на уровни 1–20.

Три слота даров и два слота амулетов относятся к основной игре. Изменения даров проверяются через сценарии сессии, боя и `npm run test:economy`.

В локальной V2 `src/v2/progression.js` применяет таблицы версии 41 для страниц Гримуара, рангов, звёзд, цветов, наборов даров и рецептов амулетов. Избранные дары взаимодействуют с окружением через контекстное действие. Отклик Рыжика и Звонки, жетоны, открытие даров и постоянный ID Астрала входят в локальное сохранение.
