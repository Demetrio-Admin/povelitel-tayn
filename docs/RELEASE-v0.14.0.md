# v0.14.0 — бой проверяет сервер

**Нужно сделать вручную, в таком порядке:**
1. **Edge Function `combat`.** Supabase → Edge Functions → *Deploy a new function* → имя `combat` → вставить весь файл `supabase/functions/combat/index.ts` (≈117 КБ) → Deploy. Проверка входа (JWT) — включена по умолчанию, не отключать.
2. **SQL.** Supabase → SQL Editor → вставить весь файл `supabase/schema.sql` → Run. Безопасно запускается повторно, прогресс игроков не трогает (добавляет колонку `combat_ctx`, функции `combat_load` / `combat_apply` и обновляет `player_action`).
3. Только потом выкладывать игру (merge в `main`). Если выложить раньше, бои не будут засчитываться («Бой не засчитан»: награды нет, зелья целы).

Что видит игрок: всё то же. Окно итога боя появляется, когда сервер проиграл запись боя и подтвердил исход; награда, штраф за поражение, остаток маны и HP приходят от сервера. Нет связи — итог ждёт, пока она вернётся. Описание — README, раздел «v0.14.0».

Откат: `git revert -m 1 <merge-коммит>` **вместе** с возвратом прежнего `schema.sql`. Функцию `combat` можно оставить: старая игра её не вызывает. Откатывать только игру нельзя: новая база не принимает победу и поражение через `combat_end` (только отступление).
