# Колдовство v0.39.1 — окно победы

После успешного боя с опытом даров окно победы не открывалось: код его отрисовки обращался к переменным `reward` и `loot`, которых нет в этой области видимости. Получался `ReferenceError: reward is not defined`; сцена уже завершала бой, но кнопка продолжения не появлялась.

Удалён лишний фрагмент подготовки награды из отрисовки опыта даров. Сапфиры по-прежнему добавляются в модель окна один раз. Начисление наград и серверная проверка не меняются.

Добавлен `npm run test:victory:render`, включённый в `npm test`: реальная функция окна и его оверлей проверяются с небольшим DOM-адаптером для обоих героев, с опытом нескольких школ и Грозы, с сапфирами и без них. Проверяются открытие, состав наград, отсутствие изменений результата, фокус и кнопка продолжения, однократное закрытие и уничтожение без перехода. Это проверка поведения отрисовщика, а не визуальная проверка в браузере.

Исправление относится только к клиенту. Дополнительных SQL-миграций или обновлений Edge Functions для v0.39.1 нет. Оно не заменяет серверные шаги выпуска v0.39.0, если они ещё не выполнены.
