# v0.35.1 — окно победы

После подтверждённой победы в обычном бою открывается новое окно: золотая рамка на дереве, портрет ведьмы или колдуна, добыча с изображениями и количеством, опыт героя и каждого использованного дара. Повышение уровня показывается отдельной строкой. Внизу — восстановление здоровья, оставшаяся мана, время боя, прерывания и кнопка «Продолжить».

Все числа берутся из подтверждённого результата боя. Окно само не начисляет награды; повторное закрытие не запускает выход из боя заново. Кнопка, Enter и Escape возвращают на карту. При большом количестве добычи прокручивается только список наград, а кнопка остаётся доступной. Окно ограничено видимой областью игры, включая узкие экраны телефона.

Новые иллюстрации хранятся в WebP с прозрачностью. Правила боя, награды, цены, сохранения и серверные функции не меняются. Для этого обновления дополнительный SQL не нужен; порядок установки ранее выпущенной админки остаётся в [v0.35.0](v0.35.0.md).

Проверка интерфейса: `npm run test:victory:browser` (Playwright; при необходимости указать `CHROME_PATH`). Тест открывает реальную сцену Phaser, вызывает обработчик подтверждённого итога и проверяет награды, оба портрета, границы игрового окна, прокрутку, возврат на карту и отсутствие повторного начисления.
