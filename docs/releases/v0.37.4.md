# v0.37.4 — редактор текущих карт и графики

Редактор `?edit` использует текущую графику города. В каталоге фасады показываются из тех же атласов, что и в игре; новые деревья, цветники, фонари, трава, мостовая и ограды получили русские названия и категории.

Исправлен перенос зданий: фасад больше не возвращается к исходным координатам при пересборке карты. Вместе с коллизией здания перемещаются его вход и точка возвращения из комнаты. Координаты самой комнаты сохраняются. Копия здания остаётся декором и не перехватывает вход оригинала.

Городская трава доступна через «Полы, трава и покрытия», можно менять её рисунок и масштаб плитки. Добавлены городские стены и ограды; новые каменные дороги в городе используют текущую светлую мостовую. Исправлены ширина и отображение городского канала.

Кнопка «Локация целиком» показывает выбранную локацию; «Все локации» позволяет увидеть весь холст. Изменение размера окна больше не возвращает камеру редактора к герою. Невидимые зоны взаимодействия не рисуются белыми пятнами.

Автосохранение, отмена, повтор, загрузка и экспорт `world.edits.js` сохраняются. Старые файлы правок остаются совместимыми. Портретное игровое окно на ПК и прогресс игроков не меняются.

Проверки: `npm test`, `npm run test:chat`, `npm run test:admin`, `npm run build`, `node tools/check-bundle.mjs`; редактор в реальном Chromium на ПК и мобильном размере, включая перетаскивание, превью фасада, перенос дома, отмену/повтор, повторный вход, экспорт/импорт и переход в комнату и обратно через «Играть с правками».
