# Бой и дуэль

Сюжетные встречи версии 2 берут уровень из сценария и используют его для расчёта здоровья и рейтингов противников. Одиночные боссы получают `1400 × S(L)` здоровья. Сюжетная арена может уточнять набор предметов поверх шаблона отряда. Первая аномалия использует один лёгкий камень.

`CombatScene` отображает бой и отправляет запись действий. `CombatManager` считает бой с фиксированными шагами. Для онлайн-игры `combat_start` фиксирует параметры героя и версию правил. `combatVerify.js` повторяет запись на сервере. SQL `combat_apply` фиксирует награду и закрывает контекст; повтор применения не должен выдавать награду снова.

Дуэль использует отдельный протокол и асинхронного соперника по сохранённой сборке. Версии берутся из `src/config/combatVersions.js` и `src/config/duelPacing.js`. Уже начатый бой сохраняет свою версию правил.

Итог с ID боя сохраняется вместе с начислением и доступен для восстановления 7 суток. См. [контракт восстановления](COMBAT_RECEIPT_PROPOSAL.md).

Проверки: `node tests/combat-replay-test.mjs`, `npm run test:duel`, `npm run test:rebalance` и проверка сгенерированного Edge.

В тестовой ветке бой рассчитывается в `HorizonBattle` шагами по 50 мс. Запись принятых команд содержит номера тиков, идентификаторы даров и предметов арены. По ней можно воспроизвести бой с тем же начальным контекстом. Тест `npm run test:v2` покрывает резонанс, заряженные предметы, отряды и Отклик спутника. Phaser использует сцену `HorizonCombatScene` с общими ассетами, анимациями, панелью даров и экраном наград. Интеграция с Edge и SQL ещё предстоит.

Настройки описаны в [таблицах баланса 41](../balance-tables/README.md).

Сюжетные и полевые пакеты обоих актов используют `mob_archetypes.csv` и `encounter_packs.csv`. Кристалл, бочка, камни, метки и прерывания входят в повтор боя вместе с зельями и Откликом. Из боя обновляется локальная кампания. Воспроизводимость пакетов и наград проверяет `npm run test:v2:acts`.

Искроцап и Морозун во вступлении используют именованные обучающие отряды. Арены двух сюжетных боссов содержат тяжёлый камень и кристалл. Подготовка каста отображается отдельной шкалой. У Августа бросок камня сбивает волну холода, а ледяной щит снимает Пролом. Ранги боевых треков дают плавный бонус от 80 до 100 процентов масштаба уровня охоты. `src/v2/battleResolution.js` объединяет повтор боя, списание настоев и расчёт награды в локальной кампании.
