# Колдовство: Магическая RPG

Мобильная браузерная RPG на Phaser 4.2.1. Основная игра поддерживает облачный прогресс через Supabase и локальный режим разработки.

Рабочие документы: [видение игры](GAME_VISION.md), [архитектура](ARCHITECTURE.md), [паспорта систем](GAME_SYSTEMS/README.md), [реестр решений](DECISIONS.md), [правила разработки](AGENTS.md).

## Запуск

```bash
npm ci
npm run dev        # vite --host: откройте адрес из консоли, с телефона тоже (та же сеть)
npm test           # тесты игровых систем и совместимости (Node, без браузера)
npm run build      # статическая сборка в dist/
# Для браузерного smoke-теста
npx playwright install chromium
npm run e2e
```

Параметры URL:
- `?reset` — сбросить локальное сохранение в этом браузере.
- `?debug` — физические хитбоксы, лог событий в консоли, `window.__witch` (services). В debug клавиша **F** мгновенно завершает исследование Телекинеза II.
- `?edit` — [редактор карты](GAME_SYSTEMS/WORLD_AND_MAPS.md#редактор-карты); `?draft` — играть с черновиком редактора из этого браузера.

Локальный режим хранит прогресс в `localStorage`. В онлайне браузер хранит токены, а прогресс хранится в Supabase.

## Управление

| Действие | Клавиатура | Мышь / тач |
|---|---|---|
| Движение | WASD / стрелки | плавающий джойстик (зажать и тянуть) или тап по земле |
| Взаимодействие с объектом в фокусе | E / Space / Enter | кнопка контекста или тап по объекту (герой сам подойдёт) |
| Способности (TK / Огонь / Астрал) | 1 / 2 / 3 | кнопки нижней панели |
| Смена цели в бою | Q / Tab | тап по объекту или врагу |
| Сумка | B / I | кнопка «Сумка» |
| Журнал заданий | J | значок книги у цели вверху или тап по плашке цели |
| Зелья в бою | 4 / 5 / 6 | круглые кнопки слева над способностями |
| Закрыть окно | Esc | кнопка в окне |

## Версия 2

[Открыть игру из этой ветки](https://htmlpreview.github.io/?https://github.com/Demetrio-Admin/povelitel-tayn/blob/v2/episode-1/play.html).

У эпизода отдельное локальное сохранение. `npm run test:v2` проверяет боевые правила. `npm run test:v2:browser` выполняет мобильное прохождение в собранной игре.
