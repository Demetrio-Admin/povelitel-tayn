# Баланс версии 41

Таблицы открываются в Excel и Google Sheets. Формат сохранения — CSV в UTF-8 с запятой в качестве разделителя. После правок запусти `npm run balance:sync`. Команда `npm run balance:sync -- --check` проверяет, совпадает ли сгенерированный модуль с таблицами.

Пустая ячейка означает, что значение предстоит определить. Эпизод использует два стартовых дара и Рыжика. Остальные каталоги подготовлены для дальнейших выпусков. Для Астрала сохранён идентификатор `seal`. Идентификаторы будущих ресурсов в таблице тиров предварительные.

## Прогноз дохода

`npm run balance:sim` считает уровни на 1-й, 30-й, 180-й и 365-й день при 20 и 400 победах в день. Основной расчёт использует контрольные доходы L1. Команда `npm run balance:sim -- --compare` добавляет сценарий, где бои дают 60% дохода. Модель применяет ступени «Лунного прилива» к победам, начисляет доход по уровню в начале дня и покупает уровни пяти треков одним кругом. 55–60 дополнительных дней на амулет и цветовые ступени — оценка из спецификации.

| Допущение | Доход на L1, 20 / 400 побед | F2P до L120 | F2P с амулетом и цветами |
| --- | ---: | ---: | ---: |
| Бои дают 60% общего дохода | 666 / 2 233 | 254 дня | 309–314 дней |
| Доход сверяется с контрольной таблицей на L1 | 550 / 1 550 | 306 дней | 361–366 дней |

## Первый тестовый эпизод

Задания 1–4 Акта I «Янтарный Бор и Погасший Очаг». Игрок отгоняет Искроцапа, заряжая камень Огнём и бросая его Телекинезом. Награда за первый бой даёт 65 монет и 3 Лунные травы. Игрок тратит 60 монет и 2 травы на усиление палочки, проверяет её в бою с Морозуном, получает Рыжика и открывает свободную охоту у Привала Грома.

Для эпизода приняты тестовые значения урона палочки, цены и откатов стартовых даров и темпа атак врагов. Первое улучшение повышает ранг темпа на 8 и сокращает интервал выстрелов с 1,50 до 1,30 с. Охота ограничена Тиром 1. Лунный прилив обновляется по календарному дню UTC.

Бой в клиенте Phaser этой ветки использует эти таблицы и локальное сохранение браузера. Серверная проверка версии 41 через `_game_rules()` и Edge `combat` ещё предстоит.
