# Колдовство v0.30 — выпуск баланса

Экономика обеих глав, три новых поручения Веды, четыре одноразовых тайника сапфиров, городской банковский подарок и компенсация изменившихся сюжетных наград старым игрокам. Мана восстанавливается быстрее на высоких уровнях; Лунный амулет возвращает 50/60/70/80% на ступенях +0/+1/+2/+3.

## Порядок обновления

Клиент GitHub Pages выпускается после серверной части. В текущей среде нет доступа администратора Supabase, поэтому эти два шага выполняются владельцем проекта.

1. В Supabase → Edge Functions открыть **combat**, заменить код содержимым `supabase/functions/combat/index.ts` из этой ветки и нажать Deploy. Файл собран автоматически. Старые записи боёв совместимы: без версии контекста применяется прежний реген 3/с и прежняя формула Лунного амулета.
2. В Supabase → SQL Editor выполнить целиком `supabase/migrations/20261007_balance_v30.sql`. Миграция рассчитана на существующую схему v0.29 и выполняется в транзакции. Повторный запуск безопасен. Новые награды старому прогрессу начисляются один раз; новые персонажи отмечаются сразу, чтобы повторный запуск не выдавал им компенсацию.
3. После успеха обоих шагов слить PR в **main**. GitHub Pages опубликует клиент v0.30.0. Новый клиент передаёт `balanceVersion: 30`; SQL сохраняет только разрешённую версию в контексте, Edge Function проверяет бой по ней. Оставшиеся вкладки v0.29 продолжают использовать старую боевую физику.

Не выполнять старую миграцию сумки после новой: она содержит старую копию `_game_rules()` и перезапишет цены. Если это произошло, повторно выполнить миграцию v0.30.

## Проверка выпуска

- После прихода в город банковское приветствие даёт 3 сапфира один раз.
- У Нэрис сюжетный Лёд II стоит 500 монет, Лёд III — 1500; сапфиры не нужны.
- Задания Веды принимаются и сдаются по цепочке. «Запас травницы» появляется после окончания главы I и выдаёт 1 сапфир.
- При открытии тайника появляется сообщение «+1 сапфир»; повторное открытие не меняет кошелёк.
- Завершённая глава II доводит героя как минимум до уровня 15.
- Бои в обновлённом клиенте подтверждаются сервером; уже начатые бои старой версии тоже принимаются.

Команды: `npm run test:balance`, `npm run balance:story`, `npm run test:balance:browser`, `node tests/combat-replay-test.mjs`, `npm run build`.

Полный набор `npm test` также содержит отдельную старую ошибку проверки позиции Агаты у банка (`tests/city-layout-test.mjs`). Баланс не переносит NPC и не меняет сохранённую раскладку редактора карт.
