# Документация и материалы разработки

Единственные актуальные источники архитектуры и продуктовых решений — [видение](../GAME_VISION.md), [архитектура](../ARCHITECTURE.md), [реестр решений](../DECISIONS.md), [паспорта систем](../GAME_SYSTEMS/README.md) и текущие исходники. При конфликте исторического документа с кодом уточняй решение владельца; не внедряй историческое ТЗ автоматически.

- `design/` — исторические проектные материалы, результаты балансировки, утверждённые художественные источники и входные данные генераторов. Не считать весь каталог действующим ТЗ и не удалять источники генераторов без проверки зависимостей.
- `recovery/` — исторические данные и документы восстановления прогресса и экономики. Сохранять для совместимости и аудита.
- `releases/` — заметки о выпусках.
- `GAME-CHAT.md`, `TELEMETRY.md`, `images/` — материалы по действующим подсистемам.

Отдельные прототипы удалены из рабочей ветки. Их прежнее состояние доступно в истории Git.
