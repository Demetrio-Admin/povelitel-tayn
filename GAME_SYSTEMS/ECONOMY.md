# Экономика

SQL подтверждает награды, торговлю, крафт, расширение сумки, улучшения амулетов и изменения кошелька. `player_wallet` и `sapphire_ledger` хранят остаток и историю сапфиров. Транзакции и квитанции защищают подтверждённые начисления от повторов. Магазин сапфиров за реальные деньги остаётся запланированным.

Канонические правила находятся в `src/config/bag.js`, `recipes.js`, `shop.js`, `sapphires.js` и связанных конфигурациях. `serverRules.js` собирает их для SQL. Старые предметы, вместимость и `pending` входят в контракт совместимости.

Проверки: `npm run test:bag`, `npm run test:shop`, `npm run test:economy`, `npm run test:admin`.

Для локальной кампании V2 остатки, рецепты, сбор, лавки и пределы сумки хранятся в `horizon_campaign`. Свежая таблица «Лунного прилива» задаёт множитель боевой добычи по числу побед за день. Бонусы за ежедневную охоту, ритуалы и сюжетные задания начисляет отдельная логика. Вводный зелёный ритуал расходует 4 травы и 2 смолы один раз. Обычный ритуал использует стоимость из таблицы.

Гром принимает лесные материалы на привале до открытия Светлодола по тому же тарифу, что и Борис. Тест чистой прогрессии использует продажу излишков, сбор, охоту, реальные цены усилений и крафт настоев по пути к обоим боссам.
