# Колдовство — переработка врагов: направление и первые концепты

**Статус:** черновые визуальные концепты для согласования; **не подключены к игре**. Дата: 2026-10-23.
**Figma:** https://www.figma.com/design/Q4FcHVYTYl3lOC7mRHlE93

## Цель и стиль

Сохранить живописный, уютно-мистический стиль леса и города, но добавить опасности враждебным существам: выразительная угрожающая поза, читаемые когти/клыки, несимметричные пропорции, следы порчи или магии. Не сводить всё к грязно-чёрной палитре: оставлять тёплые природные цвета, локальный контраст и различимую голову/оружие. Не делать аниме, пластиковые 3D-игрушки, стикеры, чистый хоррор или фотореализм.

### Эскизы первого набора

- `scavenger-adult-concept.png` — взрослый Лесной падальщик: сутулый тяжёлый лесной хищник с древесными отростками, широким зубастым черепом, янтарными глазами и удлинёнными когтями.
- `scavenger-young-concept.png` — Молодой падальщик: сухой приземистый преследователь с костяной маской, чрезмерно длинными лапами и обломанными древесными шипами. Не просто уменьшенная копия взрослого.

**Важно:** оба файла — полноразмерные изображения с тёмным фоном, это **не** игровые спрайты. До внедрения: отделить фон, сохранить прозрачность, подогнать размер и точку опоры, проверить контраст с реальной картой. В текущие ключи текстур ничего не подменялось.

## Технические ограничения

- Сохранить прежние id текстур, существующие способности, идентификаторы врагов и баланс. Изменяется только графика.
- Для поставки: PNG/WebP с **настоящим alpha**, отсутствие фона и рамок; точка опоры снизу по центру (`origin 0.5, 1`), корректный `DISPLAY_SIZE`.
- Проверить размеры против высоты героини; в проекте боевой герой ориентировочно 144 px, человек на карте около 120 px. Не создавать огромных существ вне задуманных игровых размеров.
- Проверить каждый спрайт на реальном фоне леса, города, снежной и кладбищенской локации при масштабе мобильного экрана; силуэт должен считываться без увеличения.
- Текстуры главы III из `public/assets/chapter3` частично являются временными процедурными перекрасками, им необходима самостоятельная форма, а не только новая палитра.
- После утверждения образа выпускать отдельно `art-ready` спрайты и только затем открывать отдельный PR на замену файлов/манифеста и визуальные тесты.
