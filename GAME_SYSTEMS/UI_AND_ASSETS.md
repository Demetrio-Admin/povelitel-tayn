# UI и графика

`UIScene` и подключаемые `windows*` рисуют Phaser UI, а профиль, чат и отдельные оверлеи используют DOM. Имена окон с номерами версий обозначают историю подключения. Актуальные импорты определяют, какие окна используются.

Графика загружается через `src/config/assets.manifest.js` и пакеты локаций. `assetPacks` отвечает за догрузку и заглушки. При изменении управления или окон проверь тач и разные соотношения сторон через `npm run e2e`.
