# Работа над «Колдовством»

1. Прочитай [видение](GAME_VISION.md), [архитектуру](ARCHITECTURE.md), [решения](DECISIONS.md) и [паспорта затронутых систем](GAME_SYSTEMS/README.md). Зафиксируй исходный SHA, режим игры и результат для игрока. Для задач по магии укажи, где проверять работу: основная игра или тестовая сборка версии 2.
2. Сохраняй постоянные ID, `user_id`, инвентарь, кошелёк, исследования и совместимость активных боёв. Изменение онлайн-прогресса проходит через существующий серверный контракт. Проверь последствия для клиента, JS-модели, SQL и Edge.
3. Правь исходники генераторов. Исторические миграции относятся к выпускам, для которых они созданы. Для обновления рабочей базы следуй [процедуре выпуска](GAME_SYSTEMS/RELEASE_AND_RECOVERY.md). SQL-тесты запускаются на одноразовой базе.
4. Один PR решает одну задачу. Для дефекта сохрани воспроизводящий сценарий. Для миграции проверь сохранение старых данных и повторное применение, когда оно предусмотрено. Обнови паспорт системы и внеси принятые архитектурные решения в реестр.
5. В описании PR укажи результат, затронутые контракты, выполненные проверки и условия выпуска. Различай Node, PGlite, PostgreSQL, браузер и проверку рабочего сервера.
