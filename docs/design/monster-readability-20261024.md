# Читаемость монстров на карте

Одобренный ориентир — корневик немного ниже героини, мягкая тень у ног, различимый силуэт на пёстрой дороге. Индивидуальные размеры всех 25 видов заданы в `MONSTER_WORLD_HEIGHTS` (`src/config/monster-redesign.art.js`): обычные существа 88–148 px, крупные противники 152–224 px, Хранитель сердца 252 px. Корневик — 104 px при видимом росте героини около 110 px. Дополнительный сюжетный масштаб конкретного спавна сохраняется.

`src/world/monsterArt.js` измеряет непрозрачный силуэт, игнорируя полупрозрачную пыль. Вокруг полного исходника оставляет запас; лапы/корни привязывает к исходной точке спавна. Сам рисунок не обрезается. Поэтому пустые поля разных изображений больше не делают одного врага случайно меньше другого.

При первом показе загруженной текстуры создаётся общий для её экземпляров Canvas-кэш: мягкий свет по краям и небольшое осветление передних поверхностей. Альфа сохраняется; коррекция яркости работает и без поддержки Canvas filter. Отдельная контактная тень живёт вместе с врагом, исчезает после победы и возвращается при возрождении. В бою используется тот же рисунок с пределом видимого роста 310 px, чтобы оставить место верхней панели. Герои в PvP этим модулем не обрабатываются.

Все 25 исходных файлов остаются оптимизированными прозрачными **WebP**. Сжатие `tools/art/optimize-assets.py` и пакеты Клода не изменены: дополнительных картинок/сетевых загрузок нет. Кэш создаётся только для уже загруженного и показанного вида, примерно в двойном игровом разрешении; высота основы ограничена 512 px. Обработка не выполняется каждый кадр.

## Проверка

- `node tests/monster-art-test.mjs`: силуэт и альфа-поля, наличие спавнов и WebP всех 25 видов, размер корневика, крупные враги, предел арены и исключение PvP.
- `npm test`, сборка и `node tools/check-bundle.mjs`.
- `npm run dev`, затем `/tools/ui/monster-review.html`: стенд открывает реальные сцены и пакеты всех локаций, обходит 25 видов, показывает сравнение с героиней. Кнопки проверяют скрытие/возрождение с тенью и позволяют открыть бой. Стенд создаёт тестовое локальное сохранение; в производственную сборку не включается.
