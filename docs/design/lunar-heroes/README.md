# Лунные герои

Одобренный образ ведьмы с загрузочного экрана перенесён на обоих игровых героев с прежними пропорциями: крупная голова, компактное тело, короткие ноги. Общие детали — сливовая шляпа и плащ, золотой полумесяц, бирюзовый подклад и магическая палочка. У ведьмы медные волнистые волосы, у колдуна — каштановые.

`public/assets/heroes/lunar-v1/` содержит по три прозрачных ракурса 166×240 и по три листа ходьбы 1328×240 (8 кадров) для каждого героя. Положение стоп и игровой масштаб одинаковые. Боковой ракурс смотрит вправо; движение влево зеркалится движком.

Для повторной сборки ходьбы из этих ракурсов (Python, Pillow, NumPy):

```bash
HERO_SPRITE_DIR="$PWD/public/assets/heroes/lunar-v1" \
HERO_WALK_CONFIG="$PWD/tools/art/lunar-hero-walk.json" \
python3 tools/art/hero_walk_frames.py
```

Экран выбора использует `public/assets/ui/welcome-cover-lunar-v2.webp`; оба героя нарисованы внутри общей сцены. Портреты интерфейса берутся из фронтальных текстур. Идентификаторы героев и сохранений, игровые характеристики и hitbox не менялись.
