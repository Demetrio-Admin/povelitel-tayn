# Колдовство v0.31 — профиль героя

В верхней панели и своём профиле теперь показаны сапфиры. Лунные осколки остаются ресурсом в сумке. Профиль открывается нажатием на портрет: вкладки «Герой», «Подвиги», «Сведения», постоянный крестик справа сверху, без кнопки сумки. Окно ограничено игровым экраном и прокручивается на небольших телефонах.

Дары показаны игровыми иконками с числовыми уровнями и отметкой выбора для боя. Рядом — надетые амулеты и усиления. Профиль содержит ковен и должность, вклад текущей недели, сильнейшую подтверждённую победу, количество побеждённых типов врагов, завершённые главы, дуэльный рейтинг, даты регистрации и последнего посещения. Даты показываются в часовом поясе зрителя; «В игре» означает активность за последние две минуты.

Профили других зарегистрированных игроков открываются из карточки игрока в чате и по нику в составе ковена. Публичный ответ не содержит кошелька, инвентаря, текущего здоровья и маны, UUID аккаунта или сохранённых наборов даров. У гостя есть собственный профиль, но другие игроки не могут открыть его.

## Обновление существующей базы

1. В Supabase → SQL Editor выполнить целиком `supabase/migrations/20261008_hero_profiles.sql` из этой ветки. Нужна актуальная схема v0.30. Повторный запуск безопасен; миграция не меняет цены или награды.
2. После успешной миграции слить PR в `main`. GitHub Pages выпустит клиент v0.31.0.
3. Перезагрузить игру, проверить сапфиры в HUD, открыть профиль и перейти по всем трём вкладкам. Из чата открыть другого игрока; из ковена — участника.

`supabase/schema.sql` включает обновление для новых установок. Edge Function `combat` заново разворачивать для этого выпуска не требуется: добавленные уровни врагов являются только справочными, механика проверки боя не изменилась. Если сервер ещё не обновлён до v0.30, сначала выполнить шаги выпуска v0.30.

## Уровни и победы

Все 17 типов противников получили уровень и категорию «Обычный», «Элитный» или «Босс». Они видны на карте и в бою. Урон, здоровье, награды и боевые формулы прежние. Сильнейший определяется фиксированным рангом типа врага; при равном уровне боссы и элитные враги имеют приоритет согласно каталогу.

Рекорд создаётся только из подтверждённой сервером победы. Сохраняются тип врага, время первой победы и уровень героя перед выдачей награды. Повторный ответ или другая победа над тем же типом не увеличивает счётчик уникальных типов. Дуэли не считаются победами над монстрами.

Старые подтверждённые победы восстанавливаются из `player_world`: прежние даты и уровни героя неизвестны и не выдумываются. Эти достижения сохраняются при сбросе персонажа; завершённые главы относятся к текущему прогрессу. Данные подготовлены для будущего рейтинга, отдельного рейтинга PvE в этом выпуске нет.

## Проверки

`npm run test:profile` проверяет SQL, закрытые права записи, старые победы, повторный результат, поражение, публичные поля, присутствие и повторное применение миграции. `npm run test:profile:browser` проверяет настоящий Phaser HUD, нажатие на портрет, вкладки, крестик, повторное открытие, публичную карточку и границы игрового окна на 390×638, 360×800 и 1280×900. Публичные визуальные состояния в браузерной проверке задаются фикстурой; RPC отдельно проверяется настоящим SQL через PGlite.

Полный `npm test` останавливается на прежней ошибке позиции Агаты (`tests/city-layout-test.mjs:28`). Раскладка редактора и NPC в этом выпуске не меняются. Требуется проверка миграции и профилей на рабочем Supabase после обновления владельцем.
