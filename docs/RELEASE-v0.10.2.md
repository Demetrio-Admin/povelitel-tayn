# v0.10.2 — телеметрия живого теста, 5 минут на изучение

**Нужен SQL (по желанию, но без него тест ничего не соберёт):** в Supabase SQL Editor выполнить `supabase/migrations/20261005_telemetry.sql`. Миграция добавляет таблицу `telemetry_events` и функцию `telemetry_log`, прогресс игроков не затрагивает и безопасна для повторного запуска. Без неё игра работает, телеметрия молча не отправляется.

Что изменилось: изучение Телекинеза II занимает 5 минут (раньше 60 секунд); добавлена телеметрия. Подробности — README, раздел «v0.10.2», запросы и порядок теста — `docs/TELEMETRY.md`.

Откат: `git revert -m 1 <merge-коммит>`; данные игроков не меняются. Таблицу телеметрии при откате можно оставить или удалить (`drop table public.telemetry_events cascade;`).
