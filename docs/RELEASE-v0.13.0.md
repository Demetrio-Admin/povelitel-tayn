# v0.13.0 — сбор, находки и магия в мире делает сервер

**Нужно выполнить SQL:** открыть Supabase → SQL Editor → вставить весь файл `supabase/schema.sql` → Run. Скрипт безопасно запускается повторно, прогресс игроков не трогает (добавляет операцию `world` и обновляет правила и функции). Выполнить нужно **до** или сразу после выкладки игры: новая игра со старой базой сбор и сундуки не засчитает.

Что видит игрок: всё то же, но результат решает сервер. Сбор и находки приходят только после ответа сервера; ресурсы возрождаются по часам сервера; сундук нельзя открыть второй раз с другого устройства; мана за магию в мире списывается сервером. Без связи сбор не проходит (ничего не списывается). Описание — README, раздел «v0.13.0».

Откат: `git revert -m 1 <merge-коммит>` **вместе** с возвратом прежнего `schema.sql`. Откатывать только игру нельзя: новая база не принимает от клиента состояние сбора и сундуков, а старая игра пишет его сама. Откатывать только базу тоже нельзя: новая игра отправляет сбор операцией `world`.
