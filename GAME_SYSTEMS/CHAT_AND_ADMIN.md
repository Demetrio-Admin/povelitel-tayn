# Чат и админка

`ChatService` и `ChatWindow` отображают каналы, обращения, роли и санкции. Админка использует `AdminService`. Право на действие и доступ к приватным данным определяет SQL. Административные обёртки публичных RPC ведут журнал и передают игровые операции внутренним `game_admin.core_*`.

На обновлении базы проверь, что обёртки сохранились. Проверки: `npm run test:chat`, `npm run test:admin`. Старая последовательность настройки чата относится к раннему выпуску и помечена в [историческом документе](../docs/GAME-CHAT.md).
