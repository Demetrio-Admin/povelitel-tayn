# 25 монстров — черновой арт, допущенный владельцем к публикации

Это временные альфа-PNG из общего арт-листа, на котором присутствовали рамки и подписи. Владелец явно разрешил загрузить их в `main` **после предупреждения о дефектах**. Визуальное качество не следует считать финальным: возможны ореолы, выпадения тонких ветвей, осколков, магических эффектов.

## Контроль соответствия

- В `src/config/monster-redesign.art.js` каждому из 25 вариантов соответствует собственный файл `public/assets/monster-redesign/01.png`…`25.png`.
- Идентификаторы сражений, атаки, экономика, квесты, NPC портреты не меняются.
- Босс `node_guardian` получает отдельный ключ `enemy_heart_keeper`, чтобы не повторять спрайт `forest_guardian`.
- Высоты персонажей в `DISPLAY_SIZE` сохраняются, ширина пересчитывается под реальные пропорции PNG; у нового босса 230 пикселей.
- RGBA проверяется технически. Это не ручная художественная ретушь.
- Пакет используется для боевых/мировых противников, не заменяет дружелюбных NPC и квестовые портреты.

## Откат

Удалить импорт и `Object.assign` в `assets.manifest.js`, восстановить текстуру `node_guardian` на `enemy_guardian`; затем можно удалить `monster-redesign.art.js` и `public/assets/monster-redesign`.
